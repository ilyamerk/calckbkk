# Калькулятор зарплаты

Статическая страница: один файл `index.html`, без сборки и внешних зависимостей.

## Что умеет
- Режимы расчёта: Повар, Кассир / Бариста, Другие должности, Общий подсчёт.
- Заместитель директора по залу и заместитель директора по бару доступны в списке должностей. Для них пока не подключён расчёт КПИ.
- Разбивка по надбавкам и коэффициентам, копирование расчёта в буфер.
- Результат в виде кассового чека, тёмная тема по системе, адаптив под телефон.
- Шрифты Golos Text и IBM Plex Mono лежат в `fonts/` (OFL), внешних запросов нет.

## Локально
Открой `index.html` в браузере.

## Где лежит логика
В `index.html` → `<script>`:
- `ROLES` — схема полей (подписи, подсказки, единицы, зависимости Да/Нет);
- `CALC` — формулы для должностей с доступным расчётом.

## Хостинг
Сайт развёрнут на RelaxNet (static builder) из этого репозитория.
